🏥 Doctor Appointment Scheduler

A Java-based project that simplifies patient appointment management using Data Structures and Algorithms (DSA).

🚀 Features

- Patient registration
- Appointment booking
- Patient queue management
- Automatic slot allocation
- Search appointments by ID or name
- Display all appointments and available slots

🧠 DSA Concepts Used

- Queue: Manages patients using FIFO.
- BST: Stores appointment records.
- Greedy Algorithm: Allocates the earliest available slot.
- Searching: Finds appointments by ID or patient name.

🛠️ Technologies

- Java
- Data Structures and Algorithms

▶️ How to Run

javac DoctorAppointmentScheduler.java
java DoctorAppointmentScheduler
